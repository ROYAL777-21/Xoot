# SEO Content Automation

Reviewed: 2026-06-13

This workflow creates 1 to 2 review-ready blog briefs per day for Zoot's launch-area SEO. It does not publish unreviewed AI content. The goal is to turn search intent, local service-area relevance, and human-quality editorial rules into a repeatable queue.

## Sources Used

- Google Search Central: people-first content, E-E-A-T, and avoiding search-engine-first content.
- Google SEO Starter Guide: crawlable pages, clear titles/descriptions, useful content, and realistic expectations.
- Google Business Profile guidelines: accurate service areas, real-world business representation, and no private/confidential content.
- Google structured data guidance: JSON-LD for maintainable structured data.
- Zoot internal docs: brand guide, project context, and `docs/SEO_BLOG_PLAN.md`.

Semrush MCP access is not available on the active plan. When access is enabled, export keyword rows with volume, difficulty, intent, and SERP notes into `content/seo/keyword-intent-map.json` before generating the queue.

## Daily Command

```bash
npm run seo:daily
```

Environment options:

```bash
SEO_QUEUE_DATE=2026-06-14 SEO_DAILY_COUNT=2 npm run seo:daily
```

Outputs:

- `content/seo/generated/daily-blog-queue.json`
- `content/seo/generated/daily-blog-queue.md`

## Editorial Quality Gate

Every generated brief must be reviewed before publication:

- The first section must answer the searcher's real problem, not just repeat the keyword.
- The post gets one primary keyword and a small set of natural secondary keywords.
- Local claims must match launch coverage and live operations.
- No fake testimonials, fake scarcity, unsupported guarantees, or competitor attacks.
- The CTA must match the user's scenario: book a clean, create a business rhythm, explore Care+, or save home/property notes.
- The final article must include useful FAQs, a specific local example, and a practical checklist or decision framework.

## Psychological Writing Pattern

Use this structure to keep content readable and human:

1. Name the moment: the meeting, guest check-in, tenant handover, family visit, or weekly home reset.
2. Name the tension: time pressure, trust, reputation, privacy, repeat admin, or uncertainty.
3. Give control: a checklist, decision rule, or "what to ask before booking" section.
4. Connect Zoot calmly: vetted Zooters, saved preferences, in-app communication, support routing, Care+ continuity.
5. Invite action: one direct CTA without pressure.

## Measurement

Track weekly:

- Google Search Console impressions, clicks, CTR, and average position per blog URL.
- Blog-to-signup and blog-to-booking conversion.
- Top queries by service area.
- Support and sales questions generated by each article.
- Content updates needed because launch coverage changed.

# Concierge Incident Response Runbook

For unsafe answers, privacy exposure, tool misuse or high-risk escalation failure:

1. Disable the affected control or kill switch.
2. Preserve safe logs and correlation IDs.
3. Do not copy raw sensitive chat content into issue trackers.
4. Identify affected platform: web, mobile, Edge Function or ops queue.
5. Add a regression test before re-enabling.
6. Obtain approval from the relevant owner.

Payment, refund, Booking Cover, XootCred, Care+, safety and legal incidents require human review before any customer-facing correction.

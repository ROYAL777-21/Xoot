# Concierge Human Handoff Runbook

When Concierge escalates:

1. Confirm the case is attached to the correct authenticated user where available.
2. Confirm the summary excludes access codes, private notes, payment details and raw personal identifiers.
3. Assign the queue by escalation level.
4. Review the source knowledge or tool result used.
5. Respond through the approved Zoot support channel.
6. Record any knowledge gap separately.

Do not send real customer communications from local or preview testing. Use staging-only smoke data until launch approval.

# Concierge Product Scope

The Concierge has four layers:

1. Approved knowledge and guidance.
2. Authenticated, read-only account assistance through approved server tools.
3. Navigation to existing Zoot workflows.
4. Human escalation with structured, privacy-safe context.

The Concierge may:

- answer general Zoot, booking, preparation, launch-area, onboarding and support-routing questions from approved knowledge;
- guide users to booking, support, Care+, ZootCred, referral, partnership and Zooter routes;
- summarize safe booking/support state only through approved backend tools;
- create a support-case draft or escalation request when the user asks for help or risk rules require it.

The Concierge may not:

- create, cancel, reschedule or assign a booking;
- confirm, fail, refund or alter a payment;
- issue, redeem or alter ZootCred;
- create, cancel or alter Care+ membership;
- activate, submit, approve or deny Booking Cover;
- reveal sensitive household access details;
- make legal, financial, insurance, safety, disciplinary, payout or admin decisions.

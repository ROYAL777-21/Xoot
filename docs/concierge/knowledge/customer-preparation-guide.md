# Customer Preparation Guide

Before a Xooter arrives, customers should clear personal valuables, note priority rooms, secure pets, add parking and access instructions inside protected booking fields, and photograph fragile or unusual items where useful.

Gate codes, alarm codes, lockbox details and private household-sensitive information must not be shared in chat.

# Weekly Knowledge Gap Loop

When the Concierge cannot answer a recurring question:

1. Capture a privacy-safe summary.
2. Group similar questions.
3. Identify the affected product area.
4. Create a knowledge-gap request.
5. Route it to the correct owner.
6. Track approval status.
7. Add regression tests once approved knowledge changes.
8. Measure whether the update improved resolution rate.

Recurring questions must not be converted into production answers until approved.

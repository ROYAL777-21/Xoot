# Daily Concierge Health Loop

Review daily:

- conversation volume;
- intent classification rate;
- fallback rate;
- handoff rate;
- abandonment rate;
- error rate;
- tool failure rate;
- unsafe request rate;
- security block rate;
- response latency;
- cost per conversation.

If a critical tool fails, a knowledge source is unavailable, or unsafe responses rise, disable the affected capability with the relevant control, fall back to safe static guidance, route users to support, and create an incident record.

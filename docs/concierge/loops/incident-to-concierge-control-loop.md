# Incident To Concierge Control Loop

When the Concierge produces an unsafe, misleading, incomplete or privacy-risk response:

1. Contain the issue.
2. Identify the response source.
3. Identify the tool, policy, model or knowledge failure.
4. Pause the affected intent if needed.
5. Add a regression test.
6. Create a correction proposal.
7. Stage and test the correction.
8. Record the learning.
9. Monitor recurrence.

Production incidents must never be resolved by silently broadening model authority.

# Weekly Concierge Quality Loop

Review weekly:

- resolution rate;
- human handoff completion rate;
- repeat-contact rate;
- customer satisfaction where available;
- unsupported-answer rate;
- hallucination rate;
- policy-conflict rate;
- human override rate;
- wrong-intent classification rate;
- knowledge-gap frequency;
- unsafe-data request frequency.

Allowed outputs: knowledge-gap proposals, intent-classification proposals, tool improvement proposals, test-case proposals, escalation-rule proposals and copy improvement proposals.

Not allowed: automatic edits to approved knowledge, prices, Care+ rules, Booking Cover rules, financial policy, escalation authority or autonomy.

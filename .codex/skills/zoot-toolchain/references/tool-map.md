# Zoot Tool Map

## Planning And Branch Work

- **Superpowers**: use for structured planning, TDD/debugging/verification discipline, and branch finish checklists.
- **GitHub**: use for remote branch state, PRs, review comments, Actions/CI failures, artifacts, and merge readiness.
- **CodeRabbit**: use for AI code-review loops when a PR or patch needs external review.
- **Linear**: use when a task references roadmap, sprint scope, issue status, product backlog, or acceptance tracking.

## Code And Web App

- **Build Web Apps**: use for React/Vite UI implementation, browser testing, app-quality frontend polish, and web/PWA flows.
- **Computer**: use only when desktop/browser UI inspection or interaction is necessary and no narrower connector is available.
- **Base44**: use for external prototype/app-builder context only when the task explicitly requires Base44 project work.

## Supabase And Backend

- **Supabase**: use for project metadata, tables, policies, migrations, Edge Functions, storage, Auth redirects, and secrets placement. Keep service-role keys out of browser and chat.
- **Twilio Developer Kit**: use for voice, masked calling, Verify OTP, webhook signature validation, API key setup, and call-status callback architecture.
- **OpenAI Developers**: use for support bot/API implementation, model choice, rate limits, prompt location, and safe escalation rules.

## Operations And Data

- **Airtable**: use for launch calendars, support queues, contractor pipeline, campaign status, and internal ops data when those bases are connected.
- **Semrush**, if available in a future session: use for authoritative SEO/keyword/competitor data instead of guessing. If unavailable, document that SEO recommendations are based on local docs and public/manual research.

## Native And Mobile

- **Build iOS Apps**: use for iOS native shell, SwiftUI/ActivityKit/Live Activities, app signing, simulator/browser mirroring, and App Store readiness.
- **Build macOS Apps**: use only if a macOS companion/admin app is explicitly in scope.
- **Test Android Apps**: use for emulator QA, Android performance, Play Store readiness, and native Android behavior.
- **Expo**: use only if the project introduces or inspects an Expo/React Native path. Current Zoot mobile path is Capacitor/PWA unless the user changes direction.

## Fallbacks

If a connector is unavailable or unauthenticated:

- continue with local files, templates, and docs;
- create placeholders, checklists, or scripts instead of live changes;
- clearly list the manual dashboard steps required.
